# Platform README Source

This directory is reserved for platform-specific README source drafts derived from the homepage baseline.

Each platform source should be written for its actual user journey rather than copied from the generic README.

Expected files:

- `chrome.en.md`
- `edge.en.md`
- `firefox.en.md`
- `obsidian.en.md`
- `vscode.en.md`
- `mobile.en.md`

Each platform source should cover install, first-run setup, core workflows, export behavior, privacy, limitations, troubleshooting, and related platforms.
