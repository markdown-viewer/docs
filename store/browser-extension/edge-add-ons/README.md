# Microsoft Edge Add-ons Listing Source

Use the localized browser-neutral body copy in `../locales/` for Microsoft Edge Add-ons submissions.

Edge-specific text should appear only in install instructions, Partner Center notes, or fields that explicitly require the store name. Do not insert Edge into the reusable long description body.

## Submission Rules

- Use localized short and long descriptions from `../locales/<locale>.md`.
- Do not paste full localized README files into Edge Add-ons metadata fields.
- Do not use long lists of supported engines or formats as metadata.
- Keep reviewer explanations focused on local file access, local processing, and user-selected document rendering.
