# 简体中文

## Short Description

预览带图表、公式和主题的 Markdown，并在本地导出 DOCX/PDF/HTML/EPUB。

## Long Description

docu.md Markdown Viewer 是一款 Markdown 预览和文档导出扩展，适合每天编写、审阅和分享 Markdown 的用户。你可以在浏览器中打开本地或在线 Markdown，把它作为排版完成的文档阅读，并在需要交给同事、客户、同学或审阅者时导出。

Markdown 很适合快速起草、版本管理、技术笔记、项目文档和 AI 生成内容。真正耗时的环节通常发生在交付前：图表要截图，公式不能继续编辑，代码块需要重新排版，表格也经常需要手动整理。docu.md 保留 Markdown 源文件，同时提供完成后的阅读和导出界面。

主要功能：

- 为本地文件和受支持的网页地址提供清晰的 Markdown 阅读视图。
- 导出可编辑的 DOCX Word 文档。
- 在平台支持时导出 PDF 和自包含 HTML/EPUB。
- 在 Word 输出中保留可编辑数学公式。
- 为代码块提供语法高亮。
- 提供适合商务报告、学术写作、技术笔记、阅读版式和中文排版的文档主题。
- 为大型文档提供智能渲染和缓存。
- 正常预览和导出流程在本地处理。

支持的富内容包括标准 Markdown、GitHub 风格表格和任务列表、图片、高亮代码、数学公式、SVG 内容、复杂 HTML 表格，以及更丰富的文档视觉内容。为进一步拓展文档的表达形式，docu.md 支持 PlantUML、Infographic、drawio、ECharts 等多达 9 种图表格式。

docu.md 适合技术文档、工程设计笔记、研究草稿、周报、知识库页面、README 文件和 AI 辅助写作。保存或打开 Markdown，检查渲染结果，选择主题，然后导出适合交付场景的文档格式。

如果要打开本地文件，请在扩展详情页启用文件网址访问权限。启用后，你可以从设备打开 `.md` 文件，把文件拖入浏览器，或使用浏览器的打开文件流程。对于在线 Markdown，打开受支持的网址即可让扩展渲染文档。

隐私是工作流的一部分。正常预览和导出都在扩展本地处理。为了查看或导出 Markdown 文件，你不需要把文档上传到远程渲染服务。

当你想保留 Markdown 的写作速度，同时获得更容易阅读、编辑和分享的文档输出时，docu.md 适合这个场景。

## Reviewer Note

该扩展在本地渲染用户选择的 Markdown 文件，并提供文档导出功能。只有当用户选择在浏览器中打开本地文件时，才需要文件网址访问权限。商店说明包含一次有组织的功能介绍，避免重复堆叠关键词。
