# Español

## Short Description

Previsualiza Markdown con diagramas, fórmulas, temas y exportación local DOCX/PDF/HTML/EPUB.

## Long Description

docu.md Markdown Viewer es una extensión para previsualizar Markdown y exportar documentos. Permite abrir Markdown local o en línea en el navegador, leerlo como un documento bien presentado y exportarlo cuando necesitas entregarlo, compartirlo, revisarlo o archivarlo.

Markdown es rápido para redactar, mantener versiones, escribir notas técnicas, documentar proyectos y trabajar con contenido generado por IA. El problema suele aparecer al entregar el resultado: los diagramas terminan como capturas, las fórmulas dejan de ser editables, los bloques de código necesitan nuevo formato y las tablas requieren ajustes manuales. docu.md conserva el origen Markdown y ofrece una vista terminada para lectura y exportación.

Funciones principales:

- Vista clara de Markdown para archivos locales y URLs web compatibles.
- Exportación DOCX para documentos Word editables.
- Exportación PDF y HTML/EPUB autónomo cuando la plataforma lo permite.
- Fórmulas matemáticas editables en la salida Word.
- Resaltado de sintaxis para bloques de código.
- Temas para informes, textos académicos, notas técnicas, lectura y tipografía china.
- Renderizado inteligente y caché para documentos grandes.
- Procesamiento local para los flujos normales de vista previa y exportación.

El contenido enriquecido compatible incluye Markdown estándar, tablas y listas de tareas estilo GitHub, imágenes, código resaltado, fórmulas matemáticas, contenido SVG, tablas HTML complejas y documentos visualmente más ricos. Para ampliar las formas de presentación del documento, docu.md admite hasta 9 formatos de diagramas y gráficos, incluidos PlantUML, Infographic, drawio y ECharts.

docu.md sirve para documentación técnica, notas de diseño, borradores de investigación, informes semanales, bases de conocimiento, archivos README y escritura asistida por IA. Abre o guarda el Markdown, revisa el resultado, elige un tema y exporta el formato adecuado.

Para archivos locales, activa el acceso a URLs de archivo en los detalles de la extensión. Después podrás abrir archivos `.md`, arrastrarlos al navegador o usar el flujo de abrir archivo. Para Markdown en línea, abre una URL compatible y la extensión renderizará el documento.

La privacidad forma parte del flujo: la vista previa y la exportación normales se procesan localmente en la extensión. Tus archivos Markdown no necesitan subirse a un servicio remoto de renderizado.

## Reviewer Note

La extensión renderiza localmente archivos Markdown elegidos por el usuario y ofrece exportación de documentos. El acceso a URLs de archivo solo es necesario cuando el usuario abre archivos locales en el navegador. La descripción incluye una única lista organizada de funciones.
