# Browser Extension Store Locales

This directory contains localized marketplace copy for browser extension submissions.

Each locale file must be written in the local language and must include:

- Short description
- Long description
- Reviewer note
- Store-specific notes

Do not submit English fallback text for any locale. If a locale is not ready, leave it out of the store submission until the local-language copy is complete.

## Review Rule

Before submission, review each locale manually for English fallback paragraphs and dense feature-name lists. Official names such as docu.md, Markdown, DOCX, PDF, HTML/EPUB, Chrome Web Store, and Microsoft Edge Add-ons may stay in their normal spelling.
