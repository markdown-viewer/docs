# Italiano

## Short Description

Anteprima Markdown con diagrammi, formule, temi ed esportazione locale DOCX/PDF/HTML/EPUB.

## Long Description

docu.md Markdown Viewer è un’estensione per anteprima Markdown ed esportazione di documenti. Apre Markdown locali o online nel browser, li mostra come documenti curati e li esporta quando servono file pronti per colleghi, clienti, studenti o revisori.

Markdown è rapido per bozze, controllo versione, note tecniche, documentazione di progetto e contenuti generati dall’IA. Il passaggio difficile arriva alla consegna: i diagrammi diventano screenshot, le formule non restano modificabili, i blocchi di codice vanno risistemati e le tabelle richiedono interventi manuali. docu.md mantiene la sorgente Markdown e offre una superficie di lettura ed esportazione pronta.

Funzioni principali:

- Vista Markdown pulita per file locali e URL web supportati.
- Esportazione DOCX per documenti Word modificabili.
- Esportazione PDF e HTML/EPUB autonomo dove supportato dalla piattaforma.
- Formule matematiche modificabili nell’output Word.
- Evidenziazione della sintassi nei blocchi di codice.
- Temi per report aziendali, scrittura accademica, note tecniche, lettura e tipografia cinese.
- Rendering intelligente e cache per documenti grandi.
- Elaborazione locale nei normali flussi di anteprima ed esportazione.

I contenuti ricchi supportati includono Markdown standard, tabelle e task list in stile GitHub, immagini, codice evidenziato, formule matematiche, contenuti SVG, tabelle HTML complesse e documenti visivamente più ricchi. Per arricchire meglio il formato dei documenti, docu.md supporta fino a 9 formati di diagrammi e grafici, tra cui PlantUML, Infographic, drawio ed ECharts.

docu.md è adatto a documentazione tecnica, note di progettazione, bozze di ricerca, report settimanali, knowledge base, file README e scrittura assistita dall’IA. Apri o salva il Markdown, controlla il rendering, scegli un tema ed esporta il formato più adatto.

Per i file locali, abilita l’accesso agli URL file nei dettagli dell’estensione. Poi puoi aprire file `.md`, trascinarli nel browser o usare il comando di apertura file. Per Markdown online, apri un URL supportato.

La privacy fa parte del flusso: anteprima ed esportazione normali vengono elaborate localmente nell’estensione. I file Markdown non devono essere caricati su un servizio remoto di rendering.

## Reviewer Note

L’estensione renderizza localmente i file Markdown scelti dall’utente e offre funzioni di esportazione. L’accesso agli URL file serve solo quando l’utente apre file locali nel browser. La descrizione include un solo inventario organizzato delle funzionalità.
