# Українська

## Short Description

Перегляд Markdown з діаграмами, формулами, темами й локальним експортом DOCX/PDF/HTML/EPUB.

## Long Description

docu.md Markdown Viewer — це розширення для перегляду Markdown і експорту документів. Відкривайте локальні або онлайн-файли Markdown у браузері, читайте їх як охайно оформлені документи й експортуйте, коли потрібен файл для колег, клієнтів, студентів або рецензентів.

Markdown зручний для чернеток, контролю версій, технічних нотаток, проєктної документації та вмісту, створеного за допомогою ШІ. Найбільше часу часто забирає передача далі: діаграми стають скріншотами, формули не редагуються, блоки коду треба оформлювати знову, а таблиці виправляти вручну. docu.md зберігає джерело Markdown і надає готову поверхню для читання та експорту.

Основні можливості:

- Чистий перегляд Markdown для локальних файлів і підтримуваних вебадрес.
- Експорт DOCX для редагованих документів Word.
- Експорт PDF і автономного HTML/EPUB, якщо це підтримує платформа.
- Редаговані математичні формули у Word.
- Підсвічування синтаксису для блоків коду.
- Теми документів для звітів, академічних текстів, технічних нотаток, читання й китайської типографіки.
- Розумний рендеринг і кеш для великих документів.
- Локальна обробка для звичайного перегляду й експорту.

Підтримується стандартний Markdown, таблиці й списки завдань у стилі GitHub, зображення, підсвічений код, математичні формули, SVG, складні HTML-таблиці та виразніші способи подання документа. docu.md підтримує до 9 форматів діаграм і графіків, зокрема PlantUML, Infographic, drawio і ECharts.

docu.md корисний для технічної документації, інженерних нотаток, дослідницьких чернеток, тижневих звітів, баз знань, README-файлів і письма з допомогою ШІ. Відкрийте Markdown, перевірте результат, оберіть тему й експортуйте потрібний формат.

Для локальних файлів увімкніть доступ до URL файлів у деталях розширення. Після цього можна відкривати `.md`-файли з пристрою, перетягувати їх у браузер або користуватися відкриттям файлу. Онлайн-Markdown рендериться з підтримуваних URL.

Конфіденційність є частиною процесу: звичайний перегляд і експорт виконуються локально в розширенні. Файли Markdown не потрібно завантажувати на віддалений сервіс рендерингу.

## Reviewer Note

Розширення локально відображає вибрані користувачем Markdown-файли й надає експорт документів. Доступ до URL файлів потрібен лише для відкриття локальних файлів у браузері. Опис містить один упорядкований перелік можливостей.
