# 日本語

## Short Description

図表・数式・テーマ付きで Markdown をプレビューし、DOCX/PDF/HTML をローカルで出力できます。

## Long Description

docu.md Markdown Viewer は、Markdown のプレビューと文書出力のための拡張機能です。ローカルまたはオンラインの Markdown をブラウザーで開き、整った文書として確認し、同僚、顧客、授業、レビュー向けに渡せるファイルとして出力できます。

Markdown は下書き、バージョン管理、技術メモ、プロジェクト文書、AI が生成した内容に向いています。一方で、引き渡しの段階では作業が増えがちです。図表はスクリーンショットになり、数式は編集できなくなり、コードブロックは整形し直し、表も手作業で調整する必要があります。docu.md は Markdown の原稿を保ちながら、読みやすいプレビューと出力画面を提供します。

主な機能:

- ローカルファイルと対応 Web URL の Markdown を読みやすく表示。
- 編集可能な Word 文書として DOCX 出力。
- プラットフォームが対応する場合は PDF と単体 HTML 出力。
- Word 出力内で編集可能な数式。
- コードブロックのシンタックスハイライト。
- ビジネス文書、学術文書、技術メモ、閲覧用レイアウト、中国語組版向けのテーマ。
- 大きな文書向けのスマートレンダリングとキャッシュ。
- 通常のプレビューと出力はローカル処理。

対応するリッチコンテンツには、標準 Markdown、GitHub 風の表とタスクリスト、画像、ハイライト付きコード、数式、SVG、複雑な HTML テーブル、PlantUML、Mermaid、Vega/Vega-Lite、drawio、Canvas、Infographic、Graphviz などのテキスト形式で書かれた図表やチャートが含まれます。

docu.md は、技術文書、設計メモ、研究下書き、週次レポート、ナレッジベース、README、AI 支援ライティングに適しています。Markdown を開き、レンダリング結果を確認し、テーマを選び、用途に合った形式で出力できます。

ローカルファイルを開くには、拡張機能の詳細ページでファイル URL へのアクセスを有効にしてください。その後、端末上の `.md` ファイルを開いたり、ブラウザーにドラッグしたりできます。オンライン Markdown は対応 URL から表示されます。

プライバシーもワークフローの一部です。通常のプレビューと出力は拡張機能内でローカル処理されます。Markdown ファイルをリモートのレンダリングサービスにアップロードする必要はありません。

## Reviewer Note

この拡張機能は、ユーザーが選択した Markdown ファイルをローカルでレンダリングし、文書出力機能を提供します。ファイル URL へのアクセスは、ユーザーがローカルファイルをブラウザーで開く場合にのみ必要です。説明文では機能を一度だけ整理して紹介し、キーワードの反復を避けています。
