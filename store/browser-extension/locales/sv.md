# Svenska

## Short Description

Förhandsvisa Markdown med diagram, formler, teman och lokal DOCX/PDF/HTML-export.

## Long Description

docu.md Markdown Viewer är ett tillägg för Markdown-förhandsvisning och dokumentexport. Öppna lokala eller webbaserade Markdown-filer i webbläsaren, läs dem som färdigt formaterade dokument och exportera när du behöver dela, lämna in, granska eller arkivera.

Markdown är snabbt för utkast, versionshantering, tekniska anteckningar, projektdokumentation och AI-genererat innehåll. Överlämningen är ofta det som tar tid: diagram blir skärmbilder, formler går inte längre att redigera, kodblock behöver formateras om och tabeller kräver manuella justeringar. docu.md bevarar Markdown-källan och ger samtidigt en färdig läs- och exportyta.

Viktiga funktioner:

- Ren Markdown-läsvy för lokala filer och stödda webbadresser.
- DOCX-export för redigerbara Word-dokument.
- PDF- och fristående HTML-export där plattformen stöder det.
- Redigerbara matematiska formler i Word-utdata.
- Syntaxmarkering för kodblock.
- Dokumentteman för rapporter, akademisk text, tekniska anteckningar, läslayouter och kinesisk typografi.
- Smart rendering och cache för stora dokument.
- Lokal bearbetning för vanlig förhandsvisning och export.

Stött rikt innehåll omfattar standard-Markdown, GitHub-liknande tabeller och uppgiftslistor, bilder, markerad kod, matematiska formler, SVG-innehåll, komplexa HTML-tabeller samt diagram och grafer i textbaserade format som PlantUML, Mermaid, Vega/Vega-Lite, drawio, Canvas, Infographic och Graphviz.

docu.md passar teknisk dokumentation, designanteckningar, forskningsutkast, veckorapporter, kunskapsbaser, README-filer och AI-assisterat skrivande. Öppna Markdown, granska resultatet, välj tema och exportera rätt format.

För lokala filer aktiverar du åtkomst till fil-URL:er i tilläggets detaljsida. Därefter kan du öppna `.md`-filer från enheten, dra dem till webbläsaren eller använda webbläsarens filöppning. Markdown online renderas från stödda URL:er.

Integritet är en del av arbetsflödet: vanlig förhandsvisning och export behandlas lokalt i tillägget. Dina Markdown-filer behöver inte laddas upp till en fjärrtjänst för rendering.

## Reviewer Note

Tillägget renderar användarvalda Markdown-filer lokalt och erbjuder dokumentexport. Åtkomst till fil-URL:er behövs bara när lokala filer öppnas i webbläsaren. Beskrivningen innehåller en organiserad funktionsöversikt utan upprepade nyckelordslistor.
