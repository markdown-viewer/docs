# Français

## Short Description

Prévisualisez Markdown avec diagrammes, formules, thèmes et export local DOCX/PDF/HTML/EPUB.

## Long Description

docu.md Markdown Viewer est une extension de prévisualisation Markdown et d’export de documents. Elle permet d’ouvrir des fichiers Markdown locaux ou en ligne dans le navigateur, de les lire comme des documents soignés, puis de les exporter lorsqu’ils doivent être partagés, remis, relus ou archivés.

Markdown est rapide pour rédiger, versionner, documenter un projet ou travailler à partir d’un brouillon généré par IA. La difficulté arrive souvent au moment de la livraison : les diagrammes deviennent des captures, les formules ne sont plus modifiables, les blocs de code doivent être remis en forme et les tableaux demandent des corrections manuelles. docu.md conserve la source Markdown tout en fournissant une surface de lecture et d’export prête à l’emploi.

Fonctions principales :

- Vue de lecture claire pour les fichiers locaux et les URL web prises en charge.
- Export DOCX pour des documents Word modifiables.
- Export PDF et HTML/EPUB autonome lorsque la plateforme le permet.
- Formules mathématiques modifiables dans la sortie Word.
- Coloration syntaxique des blocs de code.
- Thèmes pour rapports professionnels, textes académiques, notes techniques, lecture longue et typographie chinoise.
- Rendu intelligent et cache pour les documents volumineux.
- Traitement local pour les flux habituels de prévisualisation et d’export.

Les contenus riches pris en charge incluent Markdown standard, tableaux et listes de tâches de style GitHub, images, code coloré, formules mathématiques, contenu SVG, tableaux HTML complexes et des documents visuellement plus riches. Pour enrichir la mise en forme des documents, docu.md prend en charge jusqu’à 9 formats de diagrammes et graphiques, dont PlantUML, Infographic, drawio et ECharts.

docu.md convient à la documentation technique, aux notes de conception, aux brouillons de recherche, aux rapports hebdomadaires, aux bases de connaissances, aux fichiers README et à l’écriture assistée par IA. Ouvrez le Markdown, vérifiez le rendu, choisissez un thème et exportez le format adapté.

Pour les fichiers locaux, activez l’accès aux URL de fichiers dans les détails de l’extension. Vous pourrez ensuite ouvrir des fichiers `.md`, les glisser dans le navigateur ou utiliser le flux d’ouverture de fichier. Pour le Markdown en ligne, ouvrez simplement une URL prise en charge.

La confidentialité fait partie du flux : la prévisualisation et l’export ordinaires sont traités localement dans l’extension. Vos fichiers Markdown n’ont pas besoin d’être envoyés à un service distant de rendu.

## Reviewer Note

L’extension rend localement les fichiers Markdown choisis par l’utilisateur et propose l’export de documents. L’accès aux URL de fichiers n’est requis que pour ouvrir des fichiers locaux dans le navigateur. La description présente les fonctions une seule fois, de façon structurée.
