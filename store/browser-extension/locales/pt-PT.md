# Português (Portugal)

## Short Description

Pré-visualize Markdown com diagramas, fórmulas, temas e exportação local DOCX/PDF/HTML.

## Long Description

docu.md Markdown Viewer é uma extensão para pré-visualização de Markdown e exportação de documentos. Abra Markdown local ou online no navegador, leia-o como um documento cuidado e exporte quando precisar de um ficheiro pronto para colegas, clientes, colegas de turma ou revisores.

Markdown é rápido para rascunhos, controlo de versões, notas técnicas, documentação de projecto e conteúdo gerado por IA. A entrega é muitas vezes a parte lenta: diagramas passam a imagens, fórmulas deixam de ser editáveis, blocos de código precisam de estilo e tabelas requerem acertos manuais. O docu.md mantém a origem em Markdown e oferece uma superfície final de leitura e exportação.

Principais funcionalidades:

- Vista limpa de Markdown para ficheiros locais e URLs suportados.
- Exportação DOCX para documentos Word editáveis.
- Exportação PDF e HTML autónomo quando suportado pela plataforma.
- Fórmulas matemáticas editáveis no Word.
- Realce de sintaxe para blocos de código.
- Temas para relatórios, escrita académica, notas técnicas, leitura e tipografia chinesa.
- Renderização inteligente e cache para documentos grandes.
- Processamento local nos fluxos normais de pré-visualização e exportação.

O conteúdo avançado suportado inclui Markdown padrão, tabelas e listas de tarefas ao estilo GitHub, imagens, código realçado, fórmulas matemáticas, conteúdo SVG, tabelas HTML complexas e formas mais ricas de apresentação do documento. O docu.md suporta até 9 formatos de diagramas e gráficos, incluindo PlantUML, Infographic, drawio e ECharts.

O docu.md é útil para documentação técnica, notas de engenharia, rascunhos de investigação, relatórios semanais, bases de conhecimento, ficheiros README e escrita assistida por IA. Abra o Markdown, reveja o resultado, escolha um tema e exporte o formato adequado.

Para ficheiros locais, active o acesso a URLs de ficheiro nos detalhes da extensão. Depois pode abrir ficheiros `.md`, arrastá-los para o navegador ou usar o fluxo de abrir ficheiro. Para Markdown online, abra uma URL suportada.

A privacidade faz parte do fluxo: a pré-visualização e a exportação normais são processadas localmente na extensão. Os seus ficheiros Markdown não precisam de ser enviados para um serviço remoto de renderização.

## Reviewer Note

A extensão renderiza localmente ficheiros Markdown escolhidos pelo utilizador e oferece exportação de documentos. O acesso a URLs de ficheiro só é necessário para abrir ficheiros locais no navegador. A descrição inclui um inventário único e organizado de funcionalidades.
