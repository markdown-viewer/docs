# Português (Brasil)

## Short Description

Visualize Markdown com diagramas, fórmulas, temas e exportação local DOCX/PDF/HTML/EPUB.

## Long Description

docu.md Markdown Viewer é uma extensão para pré-visualizar Markdown e exportar documentos. Abra Markdown local ou online no navegador, leia como um documento bem formatado e exporte quando precisar entregar, compartilhar, revisar ou arquivar.

Markdown é rápido para rascunhos, controle de versão, notas técnicas, documentação de projetos e conteúdo gerado por IA. A entrega costuma ser a parte trabalhosa: diagramas viram capturas, fórmulas deixam de ser editáveis, blocos de código precisam de novo estilo e tabelas exigem ajustes manuais. O docu.md mantém a fonte em Markdown e oferece uma superfície pronta para leitura e exportação.

Principais recursos:

- Leitura limpa de Markdown para arquivos locais e URLs compatíveis.
- Exportação DOCX para documentos Word editáveis.
- Exportação PDF e HTML/EPUB autônomo quando a plataforma oferece suporte.
- Fórmulas matemáticas editáveis na saída Word.
- Destaque de sintaxe para blocos de código.
- Temas para relatórios de negócios, escrita acadêmica, notas técnicas, leitura e tipografia chinesa.
- Renderização inteligente e cache para documentos grandes.
- Processamento local nos fluxos normais de prévia e exportação.

O conteúdo enriquecido compatível inclui Markdown padrão, tabelas e listas de tarefas no estilo GitHub, imagens, código destacado, fórmulas matemáticas, conteúdo SVG, tabelas HTML complexas e formas mais ricas de apresentação do documento. O docu.md oferece suporte a até 9 formatos de diagramas e gráficos, incluindo PlantUML, Infographic, drawio e ECharts.

O docu.md é útil para documentação técnica, notas de engenharia, rascunhos de pesquisa, relatórios semanais, bases de conhecimento, arquivos README e escrita com auxílio de IA. Abra o Markdown, revise o resultado, escolha um tema e exporte o formato adequado.

Para arquivos locais, ative o acesso a URLs de arquivo nos detalhes da extensão. Depois disso, você pode abrir arquivos `.md`, arrastá-los para o navegador ou usar o fluxo de abrir arquivo. Para Markdown online, abra uma URL compatível.

A privacidade faz parte do fluxo: a prévia e a exportação normais são processadas localmente na extensão. Seus arquivos Markdown não precisam ser enviados a um serviço remoto de renderização.

## Reviewer Note

A extensão renderiza localmente arquivos Markdown escolhidos pelo usuário e oferece exportação de documentos. O acesso a URLs de arquivo só é necessário para abrir arquivos locais no navegador. A descrição contém um inventário único e organizado de recursos.
