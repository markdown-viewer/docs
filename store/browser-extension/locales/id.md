# Bahasa Indonesia

## Short Description

Pratinjau Markdown dengan diagram, rumus, tema, dan ekspor lokal DOCX/PDF/HTML.

## Long Description

docu.md Markdown Viewer adalah ekstensi untuk pratinjau Markdown dan ekspor dokumen. Buka Markdown lokal atau online di browser, baca sebagai dokumen yang rapi, lalu ekspor saat Anda membutuhkan file siap dibagikan, dikirim, ditinjau, atau diarsipkan.

Markdown cepat untuk draf, kontrol versi, catatan teknis, dokumentasi proyek, dan konten buatan AI. Tahap penyerahan sering memperlambat pekerjaan: diagram menjadi tangkapan layar, rumus tidak lagi dapat diedit, blok kode perlu ditata ulang, dan tabel membutuhkan perapihan manual. docu.md mempertahankan sumber Markdown sekaligus memberi tampilan baca dan ekspor yang siap pakai.

Fitur utama:

- Tampilan baca Markdown yang bersih untuk file lokal dan URL web yang didukung.
- Ekspor DOCX untuk dokumen Word yang dapat diedit.
- Ekspor PDF dan HTML mandiri jika didukung platform.
- Rumus matematika yang dapat diedit di output Word.
- Penyorotan sintaks untuk blok kode.
- Tema dokumen untuk laporan bisnis, tulisan akademik, catatan teknis, tata baca, dan tipografi Tionghoa.
- Rendering cerdas dan cache untuk dokumen besar.
- Pemrosesan lokal untuk pratinjau dan ekspor normal.

Konten kaya yang didukung mencakup Markdown standar, tabel dan daftar tugas gaya GitHub, gambar, kode yang disorot, rumus matematika, konten SVG, tabel HTML kompleks, serta diagram atau bagan dalam format teks seperti PlantUML, Mermaid, Vega/Vega-Lite, drawio, Canvas, Infographic, dan Graphviz.

docu.md cocok untuk dokumentasi teknis, catatan desain, draf riset, laporan mingguan, basis pengetahuan, file README, dan penulisan berbantuan AI. Buka Markdown, tinjau hasil render, pilih tema, lalu ekspor format yang sesuai.

Untuk file lokal, aktifkan akses URL file pada halaman detail ekstensi. Setelah itu Anda dapat membuka file `.md` dari perangkat, menyeretnya ke browser, atau memakai alur buka file. Markdown online dirender dari URL yang didukung.

Privasi menjadi bagian dari alur kerja. Pratinjau dan ekspor normal diproses secara lokal di ekstensi. File Markdown Anda tidak perlu diunggah ke layanan rendering jarak jauh.

## Reviewer Note

Ekstensi merender file Markdown pilihan pengguna secara lokal dan menyediakan ekspor dokumen. Akses URL file hanya diperlukan saat pengguna membuka file lokal di browser. Deskripsi berisi satu inventaris fitur yang terstruktur tanpa pengulangan kata kunci.
