# Chrome Web Store Listing Source

Use the localized browser-neutral body copy in `../locales/` for Chrome Web Store submissions.

Chrome-specific text should appear only in install instructions, reviewer notes, or fields that explicitly require the store name. Do not insert Chrome into the reusable long description body.

## Submission Rules

- Use localized short and long descriptions from `../locales/<locale>.md`.
- Do not paste full localized README files into Chrome Web Store metadata fields.
- Do not use long lists of supported engines or formats as metadata.
- Keep reviewer explanations focused on local file access, local processing, and user-selected document rendering.
