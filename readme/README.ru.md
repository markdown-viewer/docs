# docu.md Markdown Viewer

Просмотр Markdown с диаграммами, формулами, темами и локальным экспортом DOCX/PDF/HTML.

Этот README описывает docu.md на русском языке. Это пользовательская документация, поэтому она может быть подробнее короткого описания в магазине.

docu.md Markdown Viewer — расширение для просмотра Markdown и экспорта документов. Открывайте локальные или онлайн-файлы Markdown в браузере, читайте их как аккуратно оформленные документы и экспортируйте, когда нужен файл для коллег, клиентов, однокурсников или рецензентов.

Markdown удобен для черновиков, контроля версий, технических заметок, проектной документации и материалов, созданных с помощью ИИ. Сложности обычно начинаются на этапе передачи: диаграммы превращаются в скриншоты, формулы нельзя редактировать, блоки кода приходится заново оформлять, а таблицы править вручную. docu.md сохраняет исходный Markdown и даёт готовую поверхность для чтения и экспорта.

Основные возможности:

- Чистый просмотр Markdown для локальных файлов и поддерживаемых веб-адресов.
- Экспорт DOCX для редактируемых документов Word.
- Экспорт PDF и автономного HTML, если это поддерживается платформой.
- Редактируемые математические формулы в Word-документе.
- Подсветка синтаксиса для блоков кода.
- Темы для деловых отчётов, академических текстов, технических заметок, чтения и китайской типографики.
- Умный рендеринг и кэширование для больших документов.
- Локальная обработка в обычных сценариях просмотра и экспорта.

Поддерживаются стандартный Markdown, таблицы и списки задач в стиле GitHub, изображения, подсвеченный код, математические формулы, SVG, сложные HTML-таблицы, а также диаграммы и графики в распространённых текстовых форматах: PlantUML, Mermaid, Vega/Vega-Lite, drawio, Canvas, Infographic и Graphviz.

docu.md подходит для технической документации, инженерных заметок, исследовательских черновиков, еженедельных отчётов, баз знаний, README-файлов и письма с помощью ИИ. Откройте Markdown, проверьте результат, выберите тему и экспортируйте нужный формат.

Для локальных файлов включите доступ к file URL в настройках расширения. После этого можно открывать `.md`-файлы с устройства, перетаскивать их в браузер или использовать стандартное открытие файла. Для онлайн-Markdown откройте поддерживаемый URL.

Конфиденциальность встроена в рабочий процесс: обычный просмотр и экспорт выполняются локально в расширении. Markdown-файлы не нужно загружать на удалённый сервис рендеринга.
