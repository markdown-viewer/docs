# docu.md Markdown Viewer

預覽帶圖表、公式和主題的 Markdown，並在本地匯出 DOCX/PDF/HTML。

這份 README 使用繁體中文介紹 docu.md。它面向使用者與文件場景，因此可以比擴充商店裡的簡短說明更完整、更積極。

docu.md Markdown Viewer 是一款 Markdown 預覽和文件匯出擴充功能，適合每天編寫、審閱和分享 Markdown 的使用者。你可以在瀏覽器中開啟本地或線上 Markdown，把它作為排版完成的文件閱讀，並在需要交給同事、客戶、同學或審閱者時匯出。

Markdown 很適合快速起草、版本管理、技術筆記、專案文件和 AI 生成內容。真正耗時的環節通常發生在交付前：圖表要截圖，公式不能繼續編輯，程式碼區塊需要重新排版，表格也經常需要手動整理。docu.md 保留 Markdown 原始檔，同時提供完成後的閱讀和匯出介面。

主要功能：

- 為本地檔案和受支援的網頁網址提供清晰的 Markdown 閱讀視圖。
- 匯出可編輯的 DOCX Word 文件。
- 在平台支援時匯出 PDF 和自包含 HTML。
- 在 Word 輸出中保留可編輯數學公式。
- 為程式碼區塊提供語法高亮。
- 提供適合商務報告、學術寫作、技術筆記、閱讀版式和中文排版的文件主題。
- 為大型文件提供智慧渲染和快取。
- 正常預覽和匯出流程在本地處理。

支援的豐富內容包括標準 Markdown、GitHub 風格表格和任務列表、圖片、高亮程式碼、數學公式、SVG 內容、複雜 HTML 表格，以及 PlantUML、Mermaid、Vega/Vega-Lite、drawio、Canvas、Infographic 和 Graphviz 等常見文字格式編寫的圖表。

docu.md 適合技術文件、工程設計筆記、研究草稿、週報、知識庫頁面、README 檔案和 AI 輔助寫作。儲存或開啟 Markdown，檢查渲染結果，選擇主題，然後匯出適合交付場景的文件格式。

如果要開啟本地檔案，請在擴充功能詳細資料頁啟用檔案網址存取權限。啟用後，你可以從裝置開啟 `.md` 檔案，把檔案拖入瀏覽器，或使用瀏覽器的開啟檔案流程。對於線上 Markdown，開啟受支援的網址即可讓擴充功能渲染文件。

隱私是工作流的一部分。正常預覽和匯出都在擴充功能本地處理。為了查看或匯出 Markdown 檔案，你不需要把文件上傳到遠端渲染服務。

當你想保留 Markdown 的寫作速度，同時獲得更容易閱讀、編輯和分享的文件輸出時，docu.md 適合這個場景。
