# docu.md Markdown Viewer

Прагляд Markdown з дыяграмамі, формуламі, тэмамі і лакальным экспартам DOCX/PDF/HTML/EPUB.

Гэты README апісвае docu.md на беларускай мове. Тэкст зроблены для карыстальнікаў і дакументацыі, таму ён можа быць больш поўным, чым кароткае апісанне ў крамах пашырэнняў.

docu.md Markdown Viewer — пашырэнне для прагляду Markdown і экспарту дакументаў. Адкрывайце лакальныя або анлайн-файлы Markdown у браўзеры, чытайце іх як акуратна аформленыя дакументы і экспартуйце, калі патрэбны файл для калег, кліентаў, аднакурснікаў або рэцэнзентаў.

Markdown зручны для чарнавікоў, кантролю версій, тэхнічных нататак, праектнай дакументацыі і змесціва, створанага з дапамогай AI. Больш за ўсё часу часта займае перадача выніку: дыяграмы становяцца скрыншотамі, формулы нельга рэдагаваць, блокі кода трэба нанова афармляць, а табліцы выпраўляць уручную. docu.md захоўвае крыніцу Markdown і дае гатовую паверхню для чытання і экспарту.

Асноўныя магчымасці:

- Чысты прагляд Markdown для лакальных файлаў і падтрымліваных вэб-адрасоў.
- Экспарт DOCX для рэдагуемых дакументаў Word.
- Экспарт PDF і самастойнага HTML/EPUB, калі гэта падтрымліваецца платформай.
- Рэдагуемыя матэматычныя формулы ў вывадзе Word.
- Падсветка сінтаксісу для блокаў кода.
- Тэмы дакументаў для справаздач, акадэмічных тэкстаў, тэхнічных нататак, чытання і кітайскай тыпаграфікі.
- Разумны рэндэрынг і кэш для вялікіх дакументаў.
- Лакальная апрацоўка для звычайнага прагляду і экспарту.

Падтрымліваецца стандартны Markdown, табліцы і спісы задач у стылі GitHub, выявы, падсвечаны код, матэматычныя формулы, SVG, складаныя HTML-табліцы, а таксама дыяграмы і графікі ў тэкставых фарматах PlantUML, Mermaid, Vega/Vega-Lite, drawio, Canvas, Infographic, ECharts і Graphviz.

docu.md падыходзіць для тэхнічнай дакументацыі, інжынерных нататак, даследчых чарнавікоў, штотыднёвых справаздач, баз ведаў, README-файлаў і пісьма з дапамогай AI. Адкрыйце Markdown, праверце вынік, выберыце тэму і экспартуйце патрэбны фармат.

Для лакальных файлаў уключыце доступ да file URL у дэталях пашырэння. Пасля гэтага можна адкрываць `.md`-файлы з прылады, перацягваць іх у браўзер або карыстацца адкрыццём файла. Анлайн-Markdown рэндэрыцца з падтрымліваных URL.

Прыватнасць з’яўляецца часткай працэсу: звычайны прагляд і экспарт выконваюцца лакальна ў пашырэнні. Markdown-файлы не трэба загружаць у аддалены сэрвіс рэндэрынгу.
